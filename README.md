# Oasis Infobyte Data Science Internship Projects

This repository contains three projects completed as part of my Data Science Internship with Oasis Infobyte.

Projects

1. Iris Flower Classification

Objective: Classify iris flowers into Setosa, Versicolor, and Virginica.

Tools: Python, Pandas, Matplotlib, Seaborn, Scikit-learn.

Result: K-Nearest Neighbors achieved 93.3% accuracy on the test dataset.

Notebook: Iris_Flower_Classification.ipynb

2. Sales Prediction Using Python

Objective: Predict product sales using TV, radio, and newspaper advertising budgets.

Tools: Python, Pandas, Matplotlib, Seaborn, Scikit-learn.

Methods: Linear Regression and Random Forest Regression.

Notebook: Sales_Prediction.ipynb

3. Email Spam Detection

Objective: Classify text messages as spam or legitimate messages (ham).

Tools: Python, Pandas, Scikit-learn, text processing.

Model: Logistic Regression.

Result: 97.9% accuracy on the test dataset.

Notebook: Email_Spam_Detection.ipynb
